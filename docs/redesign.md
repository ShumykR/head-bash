# Редизайн авто під референси

Гілка `car-redesign`. Референси — два аркуші спрайтів, ручний піксель-арт. Беремо з них **стиль** (пропорції, затінення, колеса, скло, деталі), а не самі спрайти: кожне наше авто лишається своїм дизайном.

Порівняння до/після: `docs/redesign-compare.png` (верхня половина — було, нижня — стало). Таблиця по кожному з 270 авто: `docs/redesign-cars.md` (генерує `npx tsx scripts/redesign-report.ts`).

## Як оцінювали (спрощений ланцюжок)

Початкова ідея — «загальні риси → категорії → пара з референсом → оцінка → редизайн» для кожного авто окремо. Для 270 авто це дало б 270 майже однакових оцінок, тому ланцюжок зведено до трьох рівнів:

1. **Загальні риси** — один раз для всіх авто. Виправляються в рендері (`src/cars/sprite.ts`), тому покращують одразу всі 270.
2. **Категорії** — 7 груп за типом каркаса. Риси групи виправляються в шаблонах кузовів (`src/cars/skins.ts`, `wedge` у `toys.ts`), які спільні для десятків авто.
3. **Поштучно** — кожне авто отримує пару з найближчим референсом і оцінку до/після (1–5). Ті, що лишилися найслабшими, перемальовуються вручну.

## 1. Загальні риси референсів і чим ми відрізнялися

| Риса референсу | Як було в нас | Що зроблено |
|---|---|---|
| Колесо: товста чорна шина з відблиском угорі ліворуч, тонкий світлий обідок, маленька маточина кольору кузова | великі сірі диски зі спицями займали півколеса | новий спрайт колеса: шина ~50% радіуса, світлий обідок, маточина кольору авто з хрестиком (видно обертання) |
| Скло темне, з блідим відблиском | яскраво-блакитне, «іграшкове» | темне тоноване скло для всіх авто, колір палітри лише підфарбовує |
| Чисте затінення смугами: яскравий кант угорі, світла смуга, основний колір, темніший низ, найтемніший нижній ряд | дизеринг шахівницею і «шум» на металі | смуги без шуму, глибокий нижній ряд |
| Кузов обгортає верх коліс (арки), а не висить над ними тонкою плитою | тонка плита над великими колесами | шаблони малюють кузов нижче — до осі колеса (лише візуально, фізика не змінилась) |
| Масивний корпус, висота над колесами помітна | низькі тонкі корпуси, особливо в гоночних і санях | вищі корпуси гоночних, драгстерів, саней |
| Деталі: кутові жовті фари + помаранчевий габарит, червоні стопи, молдинг, дзеркала, лівреї й номери | дрібні точки-фари, мало декору | нові деталі в шаблонах, лівреї/свуші у гоночних |
| Насичені основні кольори | частина авто в бурих/сірих тонах | частково (див. «Що лишилося») |

Середня оцінка по 270 авто: **2.5 → 3.1**.

## 3. Поштучний редизайн

Перемальовані вручну (найнижчі оцінки):

- **Wedge** (1 → 4): клин, що обгортає колеса, діагональна червона ліврея, номер, антикрило, хромований спліттер.
- **Bumper** (2 → 3): вищий корпус, смуга, гумовий бампер навколо.
- **Toys-клини** (9 авто, 2 → 4): Rattle Bones, Fang Racer, Dark Phantom, Piranha Racer, Aero Fire Engine, Night Bat Rod, Scorpion GT, Spider Speedster, Volt Spike — масивний корпус, свуш, повітрозабірник, спойлер.
- **Драгстери** (6 авто): Dragster, Superstar Dragster, Rex Dragster, Wheelie King, Twin Devil, Knight Dragster — спільний `dragsterBody`: глибша ванна, ліврея.
- **Формули**: Race Car F1, Turbo Bones, Oval Racer — новий шаблон `formula`.
- **Сани**: Snowmobile, Snow Racer, Ice Glider, Rocket Sleigh — вищі корпуси й лівреї; полози товстіші в усіх санях.

## Що лишилося (наступні кроки)

- 181 авто отримали лише глобальний прохід (колеса/скло/тіні): істоти, роботи, блоби, гусеничні, мото. Наступний пріоритет — мото (2.5) і авто з бурими/сірими палітрами (Tow Truck, Tankette).
- Колеса в нас фізично більші за референсні відносно кузова; візуально це компенсовано нижчим кузовом. Зменшення самих коліс змінює керованість — це окреме рішення.
- У референсах кожне авто перефарбовується в колір гравця (червоний/синій). У нас кольори свої в кожного авто, а колір гравця лише на шоломі. Можна додати як опцію.
