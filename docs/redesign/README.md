# Редизайн авто під референси

Гілка `car-redesign`. Референси — два аркуші ручного піксель-арту (`CarThumbs`, `CarParts`). З них беремо **стиль** (пропорції, затінення, колеса, скло, деталі), а не самі спрайти: кожне наше авто лишається своїм дизайном.

- `evals/<колекція>.json` — оцінки кожного авто (дані).
- `cars.md` — зведена таблиця, генерується: `npx tsx scripts/redesign-report.ts`.
- `compare/<колекція>-<n>.png` — аркуші «до» (верх) / «після» (низ) для кожної партії авто.

## Ланцюжок оцінки для кожного авто

Кожне з 270 авто проходить усі чотири рівні. «До» — спрайт з основної гілки (до редизайну), «після» — фінальний.

### Рівень 1. Загальні риси (Z1–Z6, 1–5 балів)

Що об'єднує всі авто референсів:

| | Риса | 5 балів — як у референсі |
|---|---|---|
| Z1 | Колеса | товста чорна шина з відблиском, тонкий світлий обідок, маленька маточина кольору авто |
| Z2 | Скло | темне тоноване, блідий відблиск, рамка/стійки |
| Z3 | Затінення й контур | чисті смуги: світлий кант угорі, база, темний низ, темний контур; без шуму |
| Z4 | Маса кузова | корпус масивний, обгортає верх коліс (арки), не тонка плита над колесами |
| Z5 | Деталі | фари в кутах, стопи, бампери, шви дверей, дзеркала, заклепки, ручки |
| Z6 | Колір і ліврея | насичений основний колір + контрастна ліврея (смуги, свуші, номери, емблеми) |

### Рівень 2. Категорія (K1–K3, 1–5 балів)

| Група | Каркаси | K1 | K2 | K3 |
|---|---|---|---|---|
| A Легковики | sedan, coupe, sports | силует кабіни (дах, стійки, скло) | пропорції довжина/висота | решітка, бампери, фари |
| B Вантажні | van, bus, truck, box, pickup | кабіна (вікно, дзеркало, решітка) | кузов/вантаж читається | шасі, рама, кількість осей |
| C Гоночні | formula, dragster, kart | масивний клиновий корпус | крила, спойлер, повітрозабірники | ліврея, номер |
| D Позашляховики | monster, buggy | підвіска й рама видно | масивний кузов | дуги, бампери, фари |
| E Мото | bike, trike | масивний бак/обтічник | рама й двигун читаються | посадка водія |
| F Спецтехніка | tracked, digger, tractor, loco | механізм читається | масивний корпус | заклепки, труби, люки |
| G Фентезі/істоти | creature, blob, robot, saucer, rocket, hover, boat, sled, carriage, cart | образ впізнається | під образом видно «машину» (шасі, колеса, кабіна) | деталі образу (обличчя, луска, візерунок) |

### Рівень 3. Пара з референсом (P, 1–5 балів)

Для кожного авто — найближча за ідеєю машина з референсів (каталог нижче). P — наскільки наше авто дотягує до неї за якістю; у полі `gap` записано, що є в референсі й бракує нам.

### Рівень 4. Підсумок і редизайн

Підсумок = середнє з (середнє Z, середнє K, P), округлене до 0.5. Після оцінки авто перемальовується за списком прогалин (`redo`), і всі рівні оцінюються ще раз («після»).
