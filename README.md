# Head Bash Arena

Оригінальна 2D фізична гра для двох гравців у жанрі «car sumo»: збий суперника так, щоб будь-яка частина твого авто торкнулася голови його водія. Голова, що торкнулася землі (наприклад, після перевороту), теж програє раунд.
Уся графіка — процедурний піксель-арт, згенерований кодом з палітр; усі звуки — синтез WebAudio. Жодних сторонніх ассетів.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # Vitest: логіка, унікальність здібностей, механіки арен, валідація авто/мап, бот
npm run build      # продакшн-збірка в dist/
npm run e2e        # Playwright-смоук (потрібна збірка): скріншоти 915×412 і 1280×720 + перевірка консолі
```

## Керування

| | Ліворуч | Праворуч |
|---|---|---|
| Гравець 1 | `A` | `D` |
| Гравець 2 | `←` | `→` |

Дія (здібність авто): `W` для гравця 1, `↑` для гравця 2. На телефоні — кнопка-зірка над стрілками, вона заповнюється в міру перезарядки. Авто без здібності кнопки не мають.

На телефоні — по дві великі кнопки в нижніх кутах (мультитач, двоє гравців на одному екрані). У повітрі ті самі кнопки обертають авто (сальто). `Esc` — пауза, `` ` `` — показ фізичних форм.

## Що всередині

- **Фізика** (`src/physics`, `src/cars/car.ts`) — Planck.js, фіксований крок 60 Гц з акумулятором та інтерполяцією рендеру; WheelJoint з пружинною підвіскою, мотором і прогресивними відбійниками; PD-асистент вілі, керування в повітрі, повільне самопідвівання; групи/маски колізій.
- **Авто** — 270 авто у 13 колекціях. 22 оригінальні описані вручну (`src/cars/defs.ts`); решта зібрані генератором (`src/cars/factory.ts`) з 29 каркасів (седан, вантажівка, мотоцикл, гусеничний, істота, сани, тарілка…) і навісних деталей (драбина, колоди, ківш, пилка, гармата, роги, хвіст…), а маса, мотор і підвіска виводяться з пресетів архетипу. Список колекцій — `src/cars/roster.ts`, метадані й пошук — `src/cars/catalog.ts`. Кожне авто має власний **скін** — впізнаваний малюнок поверх фізичного каркаса (сани з завитими полозами, пожежна з драбиною й мигалками, двоповерховий автобус…): каркас лишається фізикою, а скін лише малює. Шаблони кузовів — `src/cars/skins.ts`, набір деталей (вікна, двері, бампери, решітки, мигалки, драбини, ферми, гусениці…) — `src/cars/draw.ts`, скіни оригінальних авто — `src/cars/originals.ts`. Рендер спрайтів (`src/cars/sprite.ts`): контур зовні силуету, п'ятитонове затінення на кожен матеріал, рамки вікон, роздільність 18 px/м.
- **Гараж** (`src/ui/garage.ts`) — сітка всіх авто з пошуком, фільтром колекцій і типів, карткою характеристик; у кутку картки — кольорові позначки типу здібності (стрибок, ривок/удар, хвиля, захист/рух, постріл, пастка, пасивка; `abilityTypes` у `src/game/abilities.ts`), легенда під сіткою. Той самий екран відкривається при виборі авто перед матчем.
- **Тіло водія** (`src/cars/rider.ts`) — під великим шоломом маленьке, навмисно непропорційне тіло: комбінезон у кольорі гравця, руки до керма, ноги. У відкритих авто й кабінах воно сидить за кузовом (у кабіні його видно крізь відкрите вікно), на мотоциклах — верхи поверх байка (руки на кермі, черевики на підніжках; шолом піднятий на висоту тіла). Тією ж фігурою намальовані носії імператорської карети. У мотоциклів велика кругла фара. Space Bike — світловий цикл: вершник лежить уздовж корпусу, а позаду тягнеться світлова стіна, що згасає (`ribbon` у `CarDef`, лише малюнок). Щоб тіло було видно, у кожному кузові під шоломом зроблено невеликий виріз до плечей (`shoulders` у `src/cars/draw.ts`), за ним видно дальню стінку кабіни; сидіння (`seat`) і деталі з `back` малюються позаду водія. Чопери (Hog, Compensator Bike) мають кермо, що доходить до рукавиць. Перевірка: `scripts/riderscan.ts`, `HEAD=1 npx tsx scripts/carsheet.ts` (кадри з водієм крупно).
- **Покадрова анімація** (`pose` у `CarPoly`) — галоп коня й оленів: чотири пози ніг (зігнуті в колінах), що змінюються в такт пройденій відстані.
- **Рухомі кінцівки** (`gait` у `CarPoly`) — ноги носіїв, павука й краба, ролики бутси: окремі спрайти, що гойдаються (або крутяться) в такт пройденій відстані. Гусениці снігобуса й Caterdog — «живі»: стрічка з траками й ковзанками малюється грою (`belt.idlers` для гусениці коротшої за колісну базу).
- **Арени** (`src/maps/defs.ts`, `src/maps/caves.ts`) — 26 арен з паралакс-фонами. Вісім із них — печери й ферми: замкнені гроти зі склепінням, по якому можна проїхати на швидкості (`cavern()`), острови всередині, ґратчасті мости над прірвою, сині підйомні промені, зелені пружні стіни, червоний лазер, що вмикається й вимикається, і пилка-маятник на ланцюгу. З решти 10 тематичних під колекції (цвинтар, зимове містечко, ферма прибульців, мотодром, вулкан, пляж, стадіон з м'ячем, свято ліхтарів, розлом, іграшковий трек): лава, шипи, пилки, обриви, падаючі блоки, рухомі платформи, трампліни, низька гравітація. Декорації малюються кодом (`src/maps/decor.ts`). Режими «випадкова арена щораунду» і «випадкові авто щораунду».
- **Предмети й голова** (`handlePair`, `scanHeads` у `src/game/game.ts`) — кинутий, скинутий чи падаючий предмет убиває, коли його власна швидкість > 1.5 м/с, а швидкість зближення з головою > 3.5 м/с (`HEAD_ITEM_SPEED`); предмет, що їде разом з авто, не рахується. Голова перевіряється на кожному кроці, а не лише при першому дотику: перекриття, що вже триває (щит закінчився, предмет був повільним), спрацьовує, щойно виконується умова. Швидкості беруться до кроку фізики, бо тверде зіткнення в тому ж кроці вже гасить предмет. Закриті кабіни прикриті дахом: предмет зупиняється шасі до сенсора голови.
- **Правила** (`src/game`) — очко за дотик до голови суперника, одночасний дотик = нічия; матч до N очок. Slow-mo, тряска, ragdoll водія, частинки.
- **Рухомі частини** (`links` у `src/cars/factory.ts`, фізика в `src/cars/car.ts`) — деталі авто з власною фізикою на шарнірах: причеп на фаркопі з власною віссю, двоколінна стріла екскаватора, шия й хвіст істот, щелепа, люлька автовишки (водій їде в ній). Шарнір має межі, пружину або мотор; частина може висіти на іншій частині. Істоти ригуються автоматично: шия з головою і хвіст забирають намальовані поверх них деталі скіна. Де сидить водій, скла немає. У закритих кузовах (легковики, пікапи, фургони, автобуси, вантажівки, монстр-траки, карети, паровози, будівельні машини) водій сидить у кабіні: стінка позаду, дах над шоломом, спереду кабіна відкрита й прорізана у спрайті наскрізь (`port` у каркасі, `cut` у полігоні). Баланс таких авто перевіряє `scripts/cabbal.ts`. Перевірка в русі: `scripts/linkcheck.ts`, ігрові кадри: `scripts/carshot.mjs`.
- **Їзда по стінах** (`WALL_GRIP` у `src/cars/car.ts`) — машину, що їде зі швидкістю, притискає до крутої поверхні тим сильніше, чим вона крутіша, тож із розгону можна заїхати на стіну й проїхати по стелі; коли швидкість падає, машина відлипає. Контури печер «Вісімка», «Кістка» і «Склеп» — гладкі сплайни (`spline` у `src/maps/caves.ts`). Заміри: `scripts/wallride.ts`. Рельєф решти арен згладжується один раз при завантаженні (`src/maps/smooth.ts`): густі контури розмиваються вздовж довжини, у рідких заокруглюються кути; прямокутні балки й опуклі острівці не чіпаються, силу задає `smooth` у мапі.
- **Виїзд з ями** (`TUNE.wheelieSlope`, `WALL_GRIP.low` у `src/cars/car.ts`) — асистент вілі згасає зі зростанням крутизни схилу: на підйомі ніс не підіймається, обидва привідні колеса лишаються на землі (раніше на схилі тягнуло одне колесо, авто буксувало й падало назад). Притискання до крутої поверхні працює й зі зупинки (`low` — частка сили без розгону). Заміри: `scripts/climb.ts` (яма зі схилами 20–50° від нерухомого старту, `climbTest` у `src/physics/probe.ts`).
- **Стрільба** (`fire` і `assistAim` у `src/game/game.ts`, снаряди в `src/game/abilities.ts`) — постріл донаводиться по висоті: кут підправляється щонайбільше на 15° від ствола (`AIM_ASSIST`) так, щоб траєкторія пройшла через шолом суперника; на рух цілі упередження немає. Для снарядів голова рахується в півтора раза більшою (`HEAD_SHOT_PAD`), а звичайне ядро чи куля штовхає кузов, у який влучає. Майже всі снаряди летять дугою. Частина снарядів сама підвертає до суперника (`seek` у снаряді: ракета Mechasaurus, плазма, торпеда, кажани; у перехоплювача — повне самонаведення). Заміри: `scripts/shothit.ts` (влучність по нерухомій машині з 5–20 м), `scripts/shotrange.ts` (дальність зі ствола й з донаведенням).
- **Здібності** (`src/cars/kit.ts` — одна таблиця на всі авто, механіки в `src/game/game.ts`) — **кожна здібність унікальна**: жодні два авто не мають однакової дії, пасивки чи вантажу (це перевіряє `tests/kit.test.ts`). 104 авто мають власну активну здібність, ще 8 — пасивку, а разом із вантажем і важками щось своє має 122 авто; решта — «чиста їзда». Хто має намальовану гармату — стріляє саме з неї: точка пострілу й кут ствола задаються поруч зі скіном (`gun` у `src/cars/factory.ts`).
  - *Реактивний двигун* (`boost` у `CarDef`): горить, поки тримаєш кнопку дії, і штовхає вперед, доки є пальне; відпустиш — пальне відновлюється. Якщо в авто є ще й інша дія, натискання запускає її, а утримання — двигун.
  - *Активні* (кнопка): стрибки (бігфут, приземлення з ударною хвилею, бекфліп, олі, місячний, гідравліка, дибки, кидок на суперника), ривки з ефектом при влучанні (жало б'є струмом, роги підкидають, жук перевертає, бампер відштовхує, акула кидає за спину), удари (клешня, бутса, ківш через себе, хвіст назад), хвилі (рик, розряд, виття плутає керування, стазис, промінь НЛО, блискавка з неба), захист (щит, панцир, дзеркало відбиває снаряди, вага, невидимість, привид), переміщення (портал, обмін місцями, петля часу, крижана стіна), 30+ різних снарядів (бумеранг-кістка, самонавідна ракета, торпеда, рейкотрон, трос евакуатора, чорнило, окріп…) і пастки, що закидаються вперед (шипи поліції, мастило, гарячий асфальт, бетон, що застигає, подарунок-пружина…).
  - *Пасивні*: амфібія пливе у воді, фургон морозива губить ріжки, що заморожують, аптечка рятує від першого удару, гусениці ратраку чіпляються за схили, шипи відкидають, гумовий м'яч відскакує, медуза б'є струмом, дрегстер лишає вогняний слід. Вантаж у кузові (колоди, труна катафалка, корова, кавуни, шини…) теж пасивка — і теж унікальний.
- **Живі арени** (`src/maps/arena.ts`) — фонові об'єкти справжні: портали Розлому телепортують (авто, снаряди, м'ячі), мертва петля Іграшкового треку проносить швидке авто по колу, промінь НЛО затягує вгору, у ворота стадіону можна забити гол (заряджає здібність), парасолі на пляжі пружинять лише того, хто приземляється на купол зверху (збоку й знизу вони не заважають), на дах воріт храму можна заїхати, а гарбузи, подарунки, сіно, корови, конуси, шини й кубики — штовхаються.
- **Плавання** (`swims` у `CarDef`, список `SWIMMERS` у `src/cars/kit.ts`, виштовхувальна сила в `stepCarFx` у `src/game/game.ts`) — човни, яхта, акули, риби, медуза, кальмар, черепаха, краб, пінгвін-слайдер, серфер, ховеркар і амфібія тримаються на воді й гребуть; решта авто в воді тонуть, а голова водія в ній програє. Заміри: `scripts/swimcheck.ts` (виїзд з пляжу в море), `scripts/sinkover.ts` (чи не загрузли колеса, зокрема причепів, у землю).
- **Раптова смерть** (`src/maps/sudden.ts`) — своя для кожної арени: рідина, що піднімається, метеорити, стіни, що сходяться, хуртовина, бомбардування, привиди, дощ із м'ячів, злива кубиків, невагомість. Рідина щоразу випадково лава або вода (лише лава, якщо хтось із авто вміє плавати). Через 25 с, якщо ніхто не впав, усе одно піднімається лава або вода.
- **Музика** (`src/audio/music.ts`) — чиптюн-секвенсор на WebAudio: трек меню, три бойові треки по черзі, окремий трек для раптової смерті. Вимикається в налаштуваннях.
- **Бот** (`src/ai/bot.ts`) — 3 рівні складності; режим «проти бота» в меню (`SHOW_BOT_MODE` у `src/ui/menu.ts`), бот також грає демо на фоні меню і турнір балансу.
- **PWA** — маніфест (landscape, fullscreen), service worker, іконки (генеруються `npx tsx scripts/icons.ts`).

## Інструменти розробника

- **Звіт про баг** (`src/debug/report.ts`, діалог — `src/debug/notes.ts`) — кнопка 🐞 (або `F9`) під час раунду: одразу фіксує момент, зупиняє гру й просить **обов'язкову нотатку** (мінімум 3 символи) та категорію (не вбило / вбило даремно / завис / фізика / інше); без нотатки звіт не зберігається. Кнопка 📍 (`F7`) — одним дотиком позначити «щойно було», гра йде далі; позначки (до 3) разом із покроковою історією потрапляють у наступний звіт. У JSON: сід і рахунок, стан раунду (`roundStart`: крок, `rngState`, арена, авто — для відтворення), фази й ненульові таймери обох авто, снаряди й предмети, **журнал голови** (`headLog`: кожен дотик до голови — з чим, швидкість, відносна швидкість, потрібний поріг і результат: `KILL`, `below-threshold`, `shield-blocked`, `own-item`…), «чорний ящик» — 12 с станів (кожні 0.1 с, з головами, статусами щита/оглушення й предметами/снарядами в радіусі 3 м від голів) та 80 подій, а в `incidents` — **кожен крок фізики за 3 с** перед позначкою (позиції, швидкості, голови, предмети поблизу). Кнопки 🐞 📍 📝 і клавіші F7/F8/F9 вимикаються в «Налаштуваннях» (перемикач «Дебаг-кнопки», за замовчуванням показані). Колеса й причепи за замовчуванням не пишуться: `window.__reportFull = true` повертає їх. Мобільний «Поділитися» / завантаження файлу, останні 3 звіти в `localStorage` (`hba-bug-reports-v1`), з консолі `__bugReport()`.

- Регресії зі звітів гравців — `tests/bugreports.test.ts`: бурульки й брили не падають під час відліку (перша — через повний інтервал після «GO»); рухома платформа, що впирається колесом у стіну, відступає назад (`crushing` у `src/maps/arena.ts`, заміри: `npx tsx scripts/platcrush.ts`); асистент нахилу працює лише з колесом на землі, тож авто, зачеплене корпусом за кут, не висить на ньому маятником. `npx tsx scripts/ghostparts.ts [мін. площа] [sheet.png]` — порівнює фізичні форми авто з намальованим спрайтом і показує невидимі ділянки, що стирчать за малюнок (за них можна зачепитися «нічим»); з PNG-шляхом малює їх пурпуровим. Фабрика (`drawnShare` у `src/cars/factory.ts`) сама прибирає фізику з навісних деталей під скіном (`hideParts`) і дрібних частин каркаса над колесами, якщо скін не малює щонайменше 35 % їхньої площі; дах над шоломом лишається (це питання балансу).
- `?gallery=1` — галерея всіх авто з характеристиками
- `?map=sky&p1=mammoth&p2=comet&debug=1` — швидкий старт матчу
- `npx tsx scripts/tune.ts` — вимірювання керованості кожного авто
- `npx tsx scripts/carcheck.ts` — валідація й тести керованості всіх авто (`CAT=dino` — лише колекція)
- `npx tsx scripts/balance.ts` — турнір ботів «кожен з кожним» для балансу
- `node scripts/maps-shots.mjs` — скріншоти всіх арен
- `npx tsx scripts/carsheet.ts out.png [колекція|id,id] [масштаб]` — аркуш спрайтів авто без браузера

## Деплой

`.github/workflows/deploy.yml` на кожній гілці запускає тести й збірку; публікує `dist/` на GitHub Pages лише з `main`.
У налаштуваннях репозиторію: **Settings → Pages → Source: GitHub Actions**.
